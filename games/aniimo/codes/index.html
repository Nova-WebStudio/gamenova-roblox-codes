📖 Comment échanger un code Aniimo

Les codes Aniimo se saisissent directement en jeu, dans les paramètres du compte.

1

Ouvre le menu Paramètres (Settings) dans Aniimo.

2

Va dans l'onglet Compte (Account).

3

Clique sur « Gift Code Redemption » (échange de code cadeau).

4

Saisis le code exactement, en respectant la casse, puis valide pour recevoir tes récompenses.

❌ Pourquoi mon code ne fonctionne pas ?

Trois causes reviennent presque toujours. Le code a expiré : s'il n'est plus dans la liste active ci-dessus, il est sans doute mort. Une faute de casse : les codes sont sensibles à la casse, utilise le bouton Copier. Déjà utilisé : chaque code n'est valable qu'une seule fois par compte.

Les « Squad Codes » d'Aniimo sont différents : ce sont des codes d'invitation à 6 caractères pour l'évènement web « Aniimo Together » (jusqu'au 27 septembre 2026), pas des codes de récompense classiques — on ne les liste donc pas ici.

❓ Questions fréquentes

Au 17 septembre 2026, deux codes sont actifs : ANIIMOGIFT (10 Glimmer, 20 000 Credits, 10 Growth Flowers, 5 Aniipod Pro) et Aniimo2026 (1× Œuf SUSUTA, 2× Aniipod Ultra, 200× Glimmer).

Ouvre les Paramètres, va dans l'onglet Compte, clique sur « Gift Code Redemption », saisis le code en respectant la casse puis valide.

Le plus souvent le code est mal saisi (la casse compte) ou a expiré. Utilise le bouton Copier pour éviter les fautes, et vérifie qu'il figure dans la liste des codes actifs ci-dessus. Un code n'est utilisable qu'une fois par compte.

Un Squad Code est un code d'invitation à 6 caractères pour l'évènement web « Aniimo Together » (jusqu'au 27 septembre 2026), où jusqu'à 6 joueurs rejoignent la même escouade. Atteindre 6 membres offre 1 Aniipod Ultra à chaque membre. C'est distinct des codes cadeaux classiques.
