## 🔎 4 observations stratégiques (à fort impact)

1. **Migration d'URL non finalisée côté Google.** Plusieurs pages rankent sur l'**ancien schéma `/codes/<jeu>.html`** (301 → `/codes-<jeu>.html`) : codes arsenal, code brook, code anime champion… Ranker sur une redirection dilue l'équité. → Vérifier que **liens internes + sitemap** ne pointent que vers les URLs canoniques neuves, et laisser Google réindexer.

2. **Singulier « code » > pluriel « codes » en FR.** Les joueurs FR tapent surtout **« code <jeu> »** (ex. « code blox fruit » = 27 100 vs « codes blox fruits » = 10). Tes pages sont titrées « Codes X ». → Inclure **les deux formes** (« code » ET « codes ») dans title/H1/intro/FAQ de chaque page codes.

3. **Saisonnalité pilotée par les updates.** Les volumes explosent autour des mises à jour (ex. « code fisch » : 20 → 1 300 en juillet & septembre ; « code king legacy » : pic à 1 300). Ton **modèle de MAJ quotidienne est parfait** pour capter ces pics — à condition que la page soit déjà indexée et rankée *avant* le pic. → Prioriser l'indexation des jeux à updates fréquentes.

4. **L'autorité est le plafond.** DT 1 / 35 backlinks explique les KD élevés sur les têtes. → En parallèle du contenu : **netliens** (annuaires gaming FR, wikis, Reddit/Discord communautaires) et **maillage interne** vers les pages Tier 1/2 pour concentrer le jus.
